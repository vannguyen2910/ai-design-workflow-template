# My case

Đây là folder làm việc của bạn. Các file bên trong đang trống, và mỗi file có sẵn các dòng gợi ý để bạn điền.

**Việc đầu tiên:** đổi tên folder này theo case của bạn, viết thường và nối bằng dấu gạch ngang, ví dụ `onboarding-redesign`.

## Where to start

1. Mở folder này bằng Obsidian (xem [`guides/05-obsidian.md`](../guides/05-obsidian.md)), rồi mở `hub/README.md` để thấy trang tổng quan của hub.
2. Mở `00-context/product-and-users.md` và điền file đầu tiên.
3. Xem bảng "What to fill each week" ở [`README.md`](../README.md) của workspace.

## Folders

```
├── AGENTS.md        luật cho AI tool (tool tự đọc file này)
├── 00-context/      thông tin nền của case: đưa vào AI tool trước tiên ở mọi bước
├── 01-discover/     scope, user-voice synthesis, competitor analysis; sources/anonymised/ và sources/_raw-private/
├── 02-define/       problem brief
├── 03-develop/      options, alignment check, prototype/
├── 04-deliver/      test plan, findings, handoff, measurement plan
├── hub/             Knowledge Hub: folder markdown (mở README.md)
├── workflow/        các step card của quy trình AI-assisted
├── _personal/       ghi chú riêng, không đưa vào AI tool
└── case-log.md      mỗi quyết định một dòng, kèm lý do
```

## Rules

1. **Ẩn danh trước khi dán vào AI tool.** Dữ liệu gốc để ở `01-discover/sources/_raw-private/`.
2. **AI chỉ trả về section của nó, và bạn tự dán vào.**
3. **Bản nháp của AI và bản bạn đã kiểm tra nằm ở hai section riêng.** Khoảng cách giữa hai bản là tỷ lệ lỗi của AI.
4. **Con số chưa xác nhận được thì ghi `assumed`.**

Hướng dẫn chi tiết nằm ở [`guides/02-set-up-your-case.md`](../guides/02-set-up-your-case.md).
