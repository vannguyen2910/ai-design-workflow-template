## Why
Links discovery to planning so users do not have to switch apps (SP-P3). This is the most direct way to address fragmentation.

## Options considered
- Save to a global favourites list.
- Save into a chosen trip (chosen).
- Copy a link to share.

## Trade-off accepted
Saving into a trip needs a trip to exist, so a first-time user is asked to start one.
