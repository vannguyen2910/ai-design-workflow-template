# Reference

Folder này chứa các trang **tra cứu**: tài liệu bạn mở ra để xem lại, không phải file làm việc hằng ngày.

Mọi file `.md` trong folder này tự hiện ở mục **Reference** của báo cáo `index.html`, kèm một dòng mô tả lấy từ dòng đầu tiên dưới tiêu đề. Muốn thêm một trang tra cứu mới (glossary, brand voice, quy ước đặt tên...), chỉ cần thả một file `.md` vào đây.

| File | Nội dung |
|---|---|
| `gates.md` | Bốn gate và các check 1a đến 4d |
| `principle-checks.md` | 10 usability heuristics của Nielsen, dùng cho Heuristic Evaluation |
| `severity-levels.md` | Thang mức độ nghiêm trọng của vấn đề usability, từ 0 đến 4 |
| `case-log.md` | Nhật ký quyết định, mỗi decision một dòng |

File `README.md` này không hiện trong báo cáo.
